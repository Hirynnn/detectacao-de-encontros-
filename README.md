# detectacao-de-encontros-
Algoritmo em Node.js e TypeScript para detecção de encontros físicos por geolocalização. Utiliza a Fórmula de Haversine, comparação de timestamps e regras de negócio para identificar encontros genéricos, entre integrantes de facções e relacionados a medidas protetivas, priorizando precisão e desempenho.
